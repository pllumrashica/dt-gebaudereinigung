# DT-Gebäudereinigung

Lokale Landingpage für DT-Gebäudereinigung auf Basis von Next.js.

## Lokal starten

Voraussetzung: Node.js 22 oder neuer.

```bash
npm install
npm run dev
```

Die Website ist anschließend unter [http://localhost:3000](http://localhost:3000) erreichbar.

## Weitere Befehle

```bash
npm run build
npm run start
npm run lint
```

Das Projekt enthält keine Anmeldefunktion und keine Konfiguration für einen Hosting-Anbieter. Es ist derzeit ausschließlich für die lokale Entwicklung vorgesehen.
